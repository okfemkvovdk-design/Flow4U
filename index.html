Import & export

Move records in and out with Excel, CSV and Word files, and keep backups.

Import

Import from Excel or CSV

Reads .xlsx, .xls, .ods and .csv files. Sheets named Staff, Projects and Tasks are picked up automatically, as is any sheet with matching column headers. You can review the changes before anything is saved.

Export

Excel workbook

Staff, projects and tasks on separate sheets. Opens in Excel, Google Sheets and LibreOffice, and can be imported back.

CSV files

One file per list, saved as UTF-8 so Arabic and other scripts display correctly in Excel.

Word report

A formatted summary of projects, tasks and staff to share or print. Opens in Microsoft Word and LibreOffice.

Backup

Download backup

One .json file with every record and attached file. Use it to keep a safe copy or move your data to another browser or computer.

Restore from backup

Replaces everything in this browser with the contents of a backup file.

Workspace

Workspace name

Delete all data

Permanently removes every staff member, project, task and attached file from this browser.
